# UroBilanz Icon-Entwürfe

Diese Mappe enthält die Icon-Entwürfe für UroBilanz.

- Vorschau: index.html
- Einzelne SVGs: svg/
- Je Entwurf gibt es eine Light- und Dark-Version.
- Finale Auswahl: liquid-glass-21B/

`liquid-glass-21B/` enthält die vorbereiteten Ebenen für ein macOS-26-Liquid-Glass-App-Icon. Auf diesem Mac fehlt aktuell Icon Composer/Xcode, deshalb nutzt die App vorerst die normale `.icns` als Fallback.
