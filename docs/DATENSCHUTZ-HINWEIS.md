# Datenschutz-Hinweis

UroBilanz verarbeitet Protokolldaten lokal auf dem eigenen Rechner.

- Keine Cloud-Anbindung.
- Kein Benutzerkonto.
- Kein Tracking.
- Kein Upload der CSV-Dateien.
- Exportierte Backups bleiben lokale Dateien.

Die Daten koennen Gesundheits- oder Koerperdaten enthalten. Deshalb sollten echte CSV-Dateien nicht in GitHub-Repositories, Cloud-Shares oder Support-Anfragen geteilt werden.
