# UroBilanz Handbuch

Die beiden oeffentlichen Handbuecher werden aus `build_manuals.py` erzeugt:

```text
python3 docs/manual/build_manuals.py
```

Die Ausgabe liegt unter `docs/output/pdf/`:

- `UroBilanz-Handbuch-DE.pdf`
- `UroBilanz-User-Manual-EN.pdf`

Vor einer Veroeffentlichung beide PDFs mit `pdftoppm` rendern und die
Seitenbilder pruefen. Die verwendeten Screenshots zeigen ausschliesslich
synthetische Demo-Daten aus `docs/screenshots/github`.
